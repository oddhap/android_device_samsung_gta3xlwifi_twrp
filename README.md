# TWRP for Samsung Galaxy Tab A 10.1 (2019)

Unofficial **TWRP 3.7.1_12** device tree for **SM-T510 / gta3xlwifi**.
ARM32 recovery, Android 12.1 base and an ARM64 Linux 4.4 kernel.

Supports touch, ADB, ROM installation, persistent recovery preferences and PIN
decryption of this LineageOS 21 port's file-based encrypted storage.

The matching LineageOS 21 ROM ZIPs automatically align the recovery compatibility
header during updates. Other Android versions or recovery images are outside
this support scope.
